# Roadmap

## Próximamente (2.0)

- [ ] Reproductor de audio integrado con control de tono y tempo
- [ ] Modo karaoke sincronizado línea por línea
- [ ] Interfaz en inglés, portugués y francés
- [ ] Renovación automática de sesiones con refresh tokens
- [ ] Virtualización de listas largas
- [ ] Tutoriales integrados
- [ ] App nativa para iOS

## 1.1 (actual)

- [x] Estadísticas de práctica: tiempo total, sesiones, top 10 y gráfico de 30 días
- [x] Tracker de práctica automático que descarta el tiempo inactivo
- [x] Endurecimiento del backend: transacciones atómicas, índices, códigos de error JWT, bcrypt de relleno y vencimiento de enlaces compartidos
- [x] Performance: carga diferida de páginas, chunks separados y ErrorBoundary global
- [x] Accesibilidad: foco atrapado y Escape en los modales, `aria-modal` y áreas táctiles de al menos 44 px
- [x] PWA: `share_target` y caché con `stale-while-revalidate` y `network-first`

## 1.0

- [x] Búsqueda de canciones y generación de cifrados con IA
- [x] Guitarra, ukelele y piano, con diagramas de acordes interactivos
- [x] Caché local, historial, autoscroll y tamaño de fuente ajustable
- [x] Modo presentación con la pantalla siempre encendida
- [x] Exportación a PDF y TXT
- [x] Transposición de tono y capo virtual
- [x] Setlists privadas y públicas
- [x] Comunidad, valoraciones y recomendaciones
- [x] App nativa Android con Capacitor
- [x] Búsqueda por progresión de acordes
- [x] Bucle de sección con autoscroll
