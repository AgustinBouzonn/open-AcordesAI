## 2024-03-05 - Accessibility improvements for dynamic UI state and toggles
**Learning:** For dynamic text fields that indicate state changes (like transpose values and autoscroll speed), screen readers do not announce the changes naturally. Furthermore, icon-only buttons need proper ARIA labels and title attributes indicating their purpose, and their decorative child icons should use `aria-hidden="true"`. Toggle buttons should also convey their current or future state dynamically rather than statically.
**Action:** Always apply `aria-live="polite"` to dynamic text components that reflect a changed state. Add `aria-label`, `title`, and `aria-hidden="true"` to icon-only buttons to ensure they're accessible to screen readers, with the labels dynamically reflecting the specific states when applicable.
