## 2024-07-19 - Accessible and Informative Tooltips for Icon Buttons
**Learning:** Icon-only buttons (like Share, Favorite, Comments, and Rating Stars) lacked context for both screen reader users and sighted users. Furthermore, disabled states didn't explicitly explain the reason. Adding dynamic tooltips (`title`) combined with `aria-label` provides crucial accessibility, and hiding inner decorative badges (like comment counts) with `aria-hidden="true"` cleans up the screen reader experience.
**Action:** When creating icon-only interactive elements, always include an `aria-label` and `title`. If an element is disabled due to a state (like not being logged in), update the tooltip to explain why (e.g., "Inicia sesión para valorar"). Use `aria-hidden="true"` on inner badges to avoid redundant announcements.
