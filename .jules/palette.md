## 2024-05-01 - Improve Accessibility for Icon-only Buttons
**Learning:** Icon-only buttons that toggle states (like favorites or showing/hiding comments) need dynamic ARIA labels and titles to accurately reflect the action that will occur or the current state (e.g., 'Quitar de favoritos' vs 'Añadir a favoritos'). Furthermore, child SVG elements (such as Lucide icons) inside these buttons should have `aria-hidden="true"` to prevent screen readers from redundantly announcing decorative graphical elements when the button itself already provides the context.
**Action:** Always add dynamic `aria-label` and `title` properties to icon-only toggle buttons, use `aria-expanded` when toggling visibility of sections, and apply `aria-hidden="true"` to child icon components in future PRs.
