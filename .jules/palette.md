## 2026-05-04 - Dynamic ARIA Labels for Toggle Buttons
**Learning:** When using icon-only buttons that toggle states (like favoriting or showing comments), static descriptions aren't enough. Screen readers need to know the current state or the action that will happen next (e.g., "Añadir a favoritos" vs "Quitar de favoritos", and `aria-expanded` for visibility toggles). Also, decorative icons within these buttons must be explicitly hidden from screen readers using `aria-hidden="true"` to prevent redundant or confusing announcements.
**Action:** Always apply dynamic `aria-label` and `title` attributes (using Spanish translations to match the UI) that reflect the current state of toggle buttons. Apply `aria-expanded` to buttons that show/hide content, and consistently use `aria-hidden="true"` on child icons in icon-only buttons.
