
## 2024-07-27 - Added dynamic ARIA labels and disabled tooltips to SongViewer
**Learning:** When a button is disabled because a user is not authenticated, adding a \`title\` tooltip (e.g., "Inicia sesión para valorar") is a great UX pattern to explain *why* it's disabled, rather than just leaving it visually faded out.
**Action:** Always consider adding explanatory tooltips to disabled interactive elements, especially those requiring authentication.
