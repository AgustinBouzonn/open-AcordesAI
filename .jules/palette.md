## 2024-03-24 - Accessible Icon-Only State Toggles
**Learning:** Icon-only buttons that toggle visibility or state (e.g., showing/hiding comments, adding/removing favorites) require dynamic `aria-label` and `title` attributes that reflect their current action context or state, rather than static descriptions. Expandable sections triggered by these buttons must also use `aria-expanded` reflecting the current boolean state, while the decorative SVG icons themselves need `aria-hidden="true"` to prevent redundant screen reader announcements.
**Action:** When creating icon-only buttons for toggling UI elements or application state, ensure the `aria-label` and `title` react to the current boolean state and always use `aria-expanded` for toggling sections while hiding inner icons with `aria-hidden="true"`.
