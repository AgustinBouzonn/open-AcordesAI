## 2025-03-01 - Dynamic ARIA attributes for UI states
**Learning:** Icon-only buttons or interactive states that toggle modes (like 'Favorite', 'Autoscroll') require dynamic `aria-label`s and `title`s to clearly communicate the action that will happen or the current state rather than a static description. Additionally, using `aria-live="polite"` on text blocks that change in response to user input (e.g., autoscroll speed value, transpose degree) allows screen readers to natively announce state changes without losing focus or context.
**Action:** Always verify if an interactive element toggles a state and, if so, map the `aria-label` and `title` to the state condition. Use `aria-live="polite"` for any text element functioning as a real-time state indicator. Apply `aria-hidden="true"` on decorative icons inside these elements.
