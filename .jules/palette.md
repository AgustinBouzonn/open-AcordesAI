## 2024-04-19 - Ensure Focus Visibility and Screen Reader Clarity on Icon Controls and Dynamic Text
**Learning:** Icon-only buttons using Lucide React icons often lack visual focus states (`focus-visible:ring-2`) and descriptive `aria-label`/`title` attributes, making keyboard navigation and screen reader use difficult. Furthermore, dynamically updating text (like autoscroll speed or transposition level) needs `aria-live="polite"` so screen readers announce state changes without interrupting the user.
**Action:** When adding or updating icon-only interactive controls, always include `aria-label`, `title`, and `focus-visible:ring-2` (with an appropriate outline color like `focus-visible:ring-brand`). Additionally, hide the purely decorative icon with `aria-hidden="true"`, and apply `aria-live="polite"` to dynamically updated status readouts.
