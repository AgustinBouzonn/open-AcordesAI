## 2024-05-12 - Dynamic ARIA attributes for toggle icon buttons
**Learning:** Icon-only toggle buttons (like "Favorite" or "Comments") must dynamically update their `aria-label` and `title` to reflect the action that will happen or the current state (e.g., "Añadir a favoritos" vs "Quitar de favoritos"). They also need appropriate state attributes like `aria-pressed` or `aria-expanded` to convey their status to screen readers. Finally, the internal decorative icons (e.g., Lucide icons) must have `aria-hidden="true"` to prevent redundant screen reader announcements.
**Action:** Whenever adding or auditing icon-only toggle buttons, always ensure dynamic labels are applied that match the current UI state, apply `aria-pressed`/`aria-expanded`, and explicitly hide the decorative child icons from screen readers using `aria-hidden="true"`.
