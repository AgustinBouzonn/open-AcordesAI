## 2025-03-09 - Accessible Icon-Only Action Buttons
**Learning:** For icon-only buttons that toggle state or trigger actions, static ARIA labels are insufficient. Dynamic `aria-label` and `title` attributes that reflect the upcoming action or current state (e.g., "Añadir a favoritos" vs "Quitar de favoritos") improve clarity for screen readers and standard users. Furthermore, decorative SVG icons inside these buttons must be explicitly hidden with `aria-hidden="true"` to prevent redundant or confusing screen reader announcements. For elements that toggle visibility of sections (like comments), `aria-expanded` is crucial.
**Action:** Always use dynamically calculated `aria-label` and `title` properties (in Spanish) for state-toggling icon buttons. Consistently apply `aria-hidden="true"` to the inner Lucide React icon components, and remember to use `aria-expanded` for expandable UI triggers.
