## 2024-05-24 - Optimize Object Filtering in Serializers
**Learning:** Using `Object.fromEntries(Object.entries({...}).filter(...))` to strip undefined values creates significant performance bottlenecks in serializers. For each row processed, it allocates a temporary intermediate object, an array of entries, processes them through a filter callback, and then maps them back to a new object. When endpoints return multiple rows, this memory overhead compounds quickly and causes heavy garbage collection pressure.
**Action:** Replace `Object.fromEntries` filtering patterns in hot paths with manual object construction and conditional assignments (`if (val !== undefined) result.key = val`). This eliminates unnecessary object/array allocations and significantly speeds up JSON serialization.
